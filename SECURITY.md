# Security

iCloudKeys handles passwords and one-time codes. Please report vulnerabilities privately through
[GitHub's private reporting](https://github.com/TowardInfinity/icloudkeys/security/advisories/new),
not in a public issue.

Include the affected version, the browser and macOS version, and steps to reproduce. Please use
test accounts, and leave real credentials out of your report.

Only the latest release is supported.
